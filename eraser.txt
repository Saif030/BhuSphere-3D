## Data Flow: Property Submission
```mermaid
sequenceDiagram
    participant Citizen as Citizen User
    participant Frontend as React Frontend
    participant API as FastAPI Backend
    participant DB as Database
    participant Officer as Verification Officer
    participant System as System Services
    
    Citizen->>Frontend: Access Submit Page
    Frontend->>Citizen: Display Submission Wizard
    Citizen->>Frontend: Enter Property Data
    Frontend->>Frontend: Validate Form Data
    Frontend->>Frontend: Convert Measurements (m²)
    Citizen->>Frontend: Upload Documents
    Frontend->>API: POST /api/submissions (Draft)
    API->>DB: Create Submission Record
    DB-->>API: Submission ID
    API-->>Frontend: SUB-2026-XXXXXX
    Frontend-->>Citizen: Show Submission ID
    
    Citizen->>Frontend: Submit for Review
    Frontend->>API: PUT /api/submissions/{id}/submit
    API->>DB: Update Status to SUBMITTED
    API->>System: Check for Duplicates
    System-->>API: Duplicate Check Results
    API->>DB: Update Status to PENDING_VERIFICATION
    API-->>Frontend: Confirmation
    Frontend-->>Citizen: Submission Submitted
    
    Officer->>Frontend: Access Verification Queue
    Frontend->>API: GET /api/submissions/queue
    API->>DB: Query Pending Submissions
    DB-->>API: Submission List
    API-->>Frontend: Queue Data
    Frontend-->>Officer: Display Queue
    
    Officer->>Frontend: Select Submission
    Frontend->>API: GET /api/submissions/{id}
    API->>DB: Get Submission Details
    DB-->>API: Full Submission Data
    API-->>Frontend: Submission Details
    Frontend-->>Officer: Show Submission Details
    
    Officer->>Frontend: Compare with Live Data
    Frontend->>API: GET /api/properties/{ulpin}
    API->>DB: Query Property Data
    DB-->>API: Property Details
    API-->>Frontend: Property Data
    Frontend-->>Officer: Show Comparison
    
    alt Field Check Required
        Officer->>Frontend: Request Field Verification
        Frontend->>API: POST /api/submissions/{id}/field-verification
        API->>DB: Create Field Verification
        API-->>Frontend: Verification ID
        Officer->>Frontend: Conduct Field Check
        Officer->>Frontend: Submit Field Results
        Frontend->>API: POST /api/field-verification/{id}/result
        API->>DB: Update Field Verification
    end
    
    Officer->>Frontend: Approve/Reject
    Frontend->>API: PUT /api/submissions/{id}/review
    API->>DB: Update Submission Status
    API->>DB: Create Audit Log
    API->>System: Trigger Integration
    
    alt Approved
        System->>DB: Update Property Records
        System->>DB: Create Property History
        System->>DB: Update Validation Status
        System->>DB: Create Notification
    end
    
    API-->>Frontend: Review Complete
    Frontend-->>Officer: Confirmation
    
    Citizen->>Frontend: Track Submission
    Frontend->>API: GET /api/submissions/track/{id}
    API->>DB: Get Submission Status
    DB-->>API: Current Status
    API-->>Frontend: Status Update
    Frontend-->>Citizen: Show Status
```

## Data Flow: Property Validation
```mermaid
sequenceDiagram
    participant Admin as Admin User
    participant API as FastAPI Backend
    participant Validation as Validation Engine
    participant DB as Database
    participant AI as AI Copilot
    
    Admin->>API: POST /api/validation/run
    API->>Validation: Trigger Validation
    Validation->>DB: Query All Properties
    DB-->>Validation: Property Data
    
    loop For Each Property
        Validation->>Validation: Check Height Mismatch
        Validation->>Validation: Check Spatial Conflicts
        Validation->>Validation: Check Ownership Issues
        Validation->>Validation: Check Geometry Validity
        
        alt Issue Found
            Validation->>AI: Request AI Analysis
            AI->>AI: Analyze Issue
            AI-->>Validation: Confidence & Suggestions
            Validation->>DB: Create Validation Issue
        end
    end
    
    Validation-->>API: Total Issues Found
    API->>DB: Create Audit Log
    API-->>Admin: Validation Report
    
    Admin->>API: GET /api/validation/issues
    API->>DB: Query Open Issues
    DB-->>API: Issues List
    API-->>Admin: Issues Dashboard
    
    Admin->>API: GET /api/validation/case/{entity}
    API->>DB: Get Case File
    DB-->>API: Full Case Data
    API-->>Admin: Case Details
    
    Admin->>API: POST /api/validation/{id}/review
    API->>DB: Update Issue Status
    API->>DB: Create Audit Log
    API-->>Admin: Review Complete
```
